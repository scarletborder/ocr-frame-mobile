# 特性清单

## 1. 两端能力矩阵

| 特性 | iOS | Android | 说明 |
|---|---|---|---|
| 拍照识别 | ✅ | ✅ | 单张；iOS `UIImagePickerController`，Android `TakePicture` + FileProvider |
| 相册多选 | ✅ ≤20 | ✅ ≤20 | 选完即开始识别，无二次确认 |
| 文件选择 | ✅ | ✅ | iOS 用 `.fileImporter`，Android 用 `OpenDocument` |
| 逐页进度 | ✅ | ✅ | 「正在分析版面…」→「已处理 k/n 个版面块」 |
| 整页 Markdown | ✅ | ✅ | 标题加 `#`/`##`，其余原样保留换行 |
| 版面块明细 | ✅ | ✅ | 标签、顺序号、文本、是否识别 |
| 两个模型槽位 | ✅ | ✅ | 版面 `.onnx` + VLM `.gguf` |
| 自动配对 mmproj | ✅ | ✅ | 选完主权重后在同目录找 `*mmproj*.gguf` |
| 手动选 mmproj | ✅ | ✅ | 第三行「视觉投影器」 |
| 模型自动收纳 | ✅ | — | iOS 会扫 `Documents` 根目录（iTunes 文件共享只能放根目录） |
| 运行方式切换 | ✅ | ✅ | 本地 GGUF / 远程 OpenAI 兼容 |
| 引擎可用性自检 | ✅ | ✅ | 设置页「已链接 / 未链接」 |
| 预设信息展示 | ✅ | ✅ | 名称、版本、产线、生成长度（来自共享核心） |
| 清空结果列表 | ✅ | ✅ | 识别中禁用 |
| 保存 / 项目 / 导出 | ❌ | ❌ | 范围外 |

## 2. 识别流水线（两端同一份）

1. **取图** → 方向归一化（EXIF）→ 整页像素上限 1200 万；
2. **版面分析**：letterbox 到 800×800（右下补 114）→ 归一化 → ONNX 推理 → `[N,7]`；
3. **后处理**：反算坐标 → 阈值 0.4 → NMS（同类 0.6 / 异类 0.98）→ 整页伪框过滤 → 阅读顺序编号；
4. **逐块识别**：按阅读顺序裁块（外扩 0.5%）→ 按标签选提示词 → VLM 贪心解码 ≤2048 token；
5. **合并**：跳过 7 类页眉页脚/页码/脚注/旁注，标题加 `#`，其余原样，拼接成整页 Markdown。

单块失败不影响整页：该块标「未识别」，几何与标签仍保留。

## 3. 预设（写死）

| 参数 | 值 | 来源 |
|---|---|---|
| 预设 | VL 线通用文档解析 `1.0` | `preset.proto` 内置 `vl_general` |
| 产线版本 | `v1.6` | `VlConfig.pipeline_version` |
| 版面框形状 | `auto`（demo 按外接矩形裁剪） | `VlConfig.shape_mode` |
| 生成长度上限 | `2048` | `DEFAULT_MAX_NEW_TOKENS` |
| 图表 / 印章识别 | 关闭 | `VlConfig.chart_recognition / seal_recognition` |
| 方向分类 / 去弯曲 | 关闭 | `VlConfig.doc_orientation_*` |
| 插图内文字 OCR | 关闭 | 部署级开关 `image_block_ocr` |

## 4. 提示词（按块标签）

| 标签 | 提示词 |
|---|---|
| `table` | `Table Recognition:` |
| `display_formula` / `inline_formula` | `Formula Recognition:` |
| `chart`（开关打开时） | `Chart Recognition:` |
| `seal`（开关打开时） | `Seal Recognition:` |
| 其余 | `OCR:` |

## 5. 失败与降级

| 场景 | 表现 |
|---|---|
| 未选模型 | 识别页红框：「请先在「设置」里选择版面分析模型。」 |
| 引擎未编译进本构建 | 设置页显示「未链接」；点识别给出可读原因（含该怎么修） |
| 版面无结果 | 单页失败：「没有检测到任何版面区域，请换一张更清晰的图片。」 |
| 单块识别失败 | 该块「未识别」，其余块正常，整页仍出 Markdown |
| 远程服务不可达 | 单块失败并保留其余结果；红框显示服务返回码与前 200 字符 |
| 相机权限被拒 | 「没有相机权限，请在系统设置里允许后重试。」 |

## 6. 明确的非目标

- 不做多文档/多任务队列；
- 不做结果持久化与历史记录；
- 不做设置项的自由组合（预设是写死的，避免 demo 变成配置台）；
- 不为性能做图片预裁剪（整页直送版面模型）。
